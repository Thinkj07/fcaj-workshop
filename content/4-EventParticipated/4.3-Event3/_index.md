# Summary Report: First Cloud AI Journey × Agentic AI Build Week (FCAJ × AABW)

### 1. Event Purpose

- Showcase real-world product solutions created using Agentic AI and AWS cloud services during Build Week.
- Explore practical use cases: crowd monitoring, omni-channel ordering bots, Solution Architect copilots, and strategic business intelligence platforms.
- Learn best practices for rapid Minimum Viable Product (MVP) prototyping, cloud cost management, and cross-functional team collaboration under tight deadlines.

### 2. Speakers List 

- **3KA Team** – S.H.E.P.H.E.R.D. Project
- **One Team** – KFC Bot Agent Project
- **SA Professional Team** – SA Professional AI Native App Project
- **Signal Scout Team** – Signal Scout Platform

### 3. Key Highlights

- **S.H.E.P.H.E.R.D. Project (3KA Team):** A real-time crowd density and hazard monitoring solution combining Computer Vision (YOLO + ByteTrack), Amazon SageMaker inference, and Bedrock AgentCore to deliver early alerts and an interactive natural-language Operator Copilot.
- **KFC Bot Agent (One Team):** An omni-channel conversational agent (Zalo, WhatsApp) operating on a "Design once, deploy everywhere" architecture. Handles end-to-end ordering, cart management, and promotions with low latency and predictable cloud costs (~$88/month for 500 orders/day).
- **SA Professional AI Native App:** An AI copilot for Solution Architects that converts BRD/PRD documents into structured requirement catalogs, editable Draw.io/AWS architecture diagrams, IaC templates, and ap-southeast-1 cost estimates in minutes.
- **Signal Scout Platform:** An enterprise strategic intelligence system that aggregates fragmented corporate signals, validates evidence, and generates actionable scenarios using AWS Bedrock, Lambda, DynamoDB, Amplify, and WAF with transparent cost scaling tiers.

### 4. Key Takeaways

- Mastered the lifecycle of taking an AI concept from problem definition to a functional demo-ready MVP.
- Understood that effective Agentic AI requires integration with reliable tools, business data, and validation steps rather than simple text generation.
- Learned how to unify computer vision, AI agents, real-time dashboards, and cloud inference for complex operational monitoring.
- Acquired modular architectural principles and techniques for optimizing cloud spending from the MVP stage.

### 5. Application to Work

- Adopt a rapid MVP mindset to prototype and validate technical concepts quickly in personal and team projects.
- Design intelligent agents capable of invoking external APIs and querying verified business data for accurate task execution.
- Incorporate cost awareness, latency benchmarking, and observability features early into every AWS architecture design.

### 6. Personal Experience

Attending **FCAJ × AABW** was an incredibly inspiring and practical experience. Beyond the polished project demonstrations, I gained deep appreciation for the teams' problem-solving resilience and technical creativity. The event clearly demonstrated that impactful AI applications require not only powerful models, but also robust cloud architecture, trustworthy data pipelines, and a user-centric design approach.
